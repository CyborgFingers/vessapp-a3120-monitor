iSCSI Session Statistics

To access to the iSCSI Management–Sessions Statistics:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administrative Tools icon.
  3. Click on the iSCSI Management icon.
  4. Click the Sessions tab in Management View.
    The window displays session information.
    Click the Statistics link to see session statistics.
    Click the Information link to return to the session information.

Statistics (in alphabetical order)

  • Controller ID – Subsystem Controller ID.
  • Port ID – Controller Port ID.
  • Session ID – The index number for this iSCSI session.
  • Session Received Counts
    • Command PDUs
    • Data Octets
    • Login Command PDUs
    • Logout Command PDUs
    • NOP-out PDUs
    • SCSI Command PDUs
    • SCSI Data Write PDUs
    • SNACK Request PDUs
    • Task Management Command PDUs

  • Session Transmitted Counts
    • Async Connection Drop Request
    • Async Logout Request
    • Async PDUs
    • Async Target Reset
    • Data Octets
    • ISCSI Response PDUs
    • Login Response PDUs
    • Logout Connection Recovery
    • Logout Response PDUs
    • Logout Session Close
    • Logout Target Request
    • NOP-In PDUs
    • R2T PDUs
    • Reject Format
    • Reject Data Digest
    • Reject Data SNACK
    • Reject Full Feature
    • Reject Header Digest
    • Reject PDUs
    • Reject Restart
    • Response PDUs
    • SCSI Data Read PDUs
    • Status Authentication
    • Status Authentication Failed
    • Status Bad Version
    • Status Conflict
    • Status Forbidden
    • Status Move Temporary
    • Status Move Permanent
    • Status Not Found
    • Status Proxy
    • Status Remove
    • Status Target Error
    • Status Unavailable
    • Task Management Response PDUs
    • Text Response PDUs

  • Other Session Counts
    • Header Digest Errors
    • Data Digest Errors
    • Connection Time-out Errors
    • Frame Errors

A detailed explanation of these iSCSI functions, how and when they are used, and their relationship to one another is beyond the scope of this document. For more information, contact the Internet Engineering Task Force at http://www.ietf.org/.
