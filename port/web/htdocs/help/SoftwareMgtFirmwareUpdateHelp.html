Firmware Update

The Software Management–Firmware Update tab enables you update the firmware on the RAID subsystem.

Before you begin, go the the website and download the latest firmware update image (.img) file to your TFTP server or to your PC. The firmware update image file includes all of the firmware components for the , including:

  • Redboot ROM
  • Kernel
  • Firmware
  • Software
  • Ramdisk
  • SEP Firmware
  • Redboot RAM
  • OEM Customization

To update the firmware from a TFTP server:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administrative Tools icon.
  3. Click the Software Management icon.
  4. Click the Firmware Update tab.
  5. Do one of the following:
    • Click the Download from TFTP Server option, then click the Next button.
    • From the Firmware Update tab dropdown menu, choose Download from TFTP Server.
  6. Enter the hostname or IP address of your TFTP server in the field provided.
  7. Enter the port number of your TFTP server in the field provided (69 is the default).
  8. Enter the filename of the Firmware Update file in the field provided.
  9. Click the Submit button.
  10. When the download is completed, click the Next button.
    A popup message appears warning you not to reboot the during the firmware update procedure.
  11. In the popup message, click the OK button.
    The update progress displays. Then a popup message appears to tell you to reboot the
  12. In the popup message, click the OK button.
  13. Shutdown the RAID subsystem.
  14. Turn on both power switches on the RAID subsystem.
    When the RAID subsystem boots, it will run the new firmware.

To update the firmware from your PC:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administrative Tools icon.
  3. Click the Software Management icon.
  4. Click the Firmware Update tab.
  5. Do one of the following:
    • Click the Download Flash File from Local File through HTTP option, then click the Next button.
    • From the Firmware Update tab dropdown menu, choose Download from Local File.
  6. Enter the filename of the Firmware Update file in the field provided.
    Or, click the Browse... button and select the Firmware Update file in the Open dialog box.
  7. Click the Submit button.
  8. When the download is completed, click the Next button.
    A popup message appears to warn you not to reboot the during the firmware update procedure.
  9. In the popup message, click the OK button.
    The update progress displays. Then a popup message appears to tell you to reboot the .
  10. In the popup message, click the OK button.
  11. Shutdown the RAID subsystem.
  12. Turn on both power switches on the RAID subsystem.
    When the RAID subsystem boots, it will run the new firmware.

Note 1: After you click the Submit button, if displays this message: error transferring image, you entered an incorrect file name or an incorrect location. Check the information and try again.

Note 2: You can delay restarting the and continue running the previous firmware, if necessary.
