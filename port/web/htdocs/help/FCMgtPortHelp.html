Fibre Channel Port

The Fibre Channel Management–Port tab enables you to see the current Data Port settings on the Controller, including:

  • State – Online, Offline, Unknown
  • Port Identifier – A hexadecimal name for this port
  • Topology Attached – See the table, below
  • WWNN – World Wide Node Name ()
  • WWPN – World Wide Port Name ()
  • Fabric WWNN – World Wide Node Name (appears when connected to a switch)
  • Fabric WWPN – World Wide Port Name (appears when connected to a switch)
  • Current Speed – 4 Gb/s, 2 Gb/s, or 1 Gb/s
  • Link Type – Laser Long Wave or Laser Short Wave
  • Symbolic Name – A text name for this port
  • Link Speed* – 4 Gb/s, 2 Gb/s, 1 Gb/s, or Auto
  • Topology* – NL-Port, N-Port, or Auto
  • Hard ALPA* – Address can be 0 to 254. 255 means this feature is disabled
  • Alias WWPN

* Denotes items that you can change under Port Settings.

The table below shows the type of attached topology you will achieve based on your connection type and the configured topology you select:

Fibre Channel Attached Topology
  Configured Topology
Connection Type N-Port NL-Port
Switch Fabric Direct Public Loop
Direct Point to Point Private Loop

Example 1: If you connect the to a Fibre Channel switch and select NL-Port topology, you will create a Public Loop attached topology.

Example 2: If you have a Point to Point attached topology, you made a direct connection (no switch) and selected N-port topology.

There are no user settings on this screen. Click on Port1 or Port2 to access settings for this port.

From this point, you can link to Node Status, Port Statistics, SFP (transceiver) Status, a list of Logged-in Devices and a list of Initiators.

To access this tab:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Fibre Channel Management icon.
  4. Click the Port tab in Management View.
