SSH

's Secure Shell (SSH) service enables you to access 's Command Line Interface (CLI) through a network connection.

To change the SSH settings:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administration Tools icon.
  3. Click the SSH link in Management view.
  4. Enter the Telnet Port number.
    22 is the default.
  5. Enter the Maximum Number of Connections.
    4 is the default.
  6. Enter the Session Time Out interval.
    24 minutes is the default.
  7. When you are done, click the Submit button.
  8. Click OK in the confirmation box to restart the SSH service with your changes.

To change the SSH Automatic/Manual start setting:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administration Tools icon.
  3. Click the SSH link in Management view.
  4. Under Startup Type:
    • Click the Automatic option to start the service automatically during system startup.
    • Click the Manual option to start the service manually (the service does not start during system startup).
  5. Click the Submit button.

To manually start, restart or stop the SSH service:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administration Tools icon.
  3. Click the SSH link in Management view.
  4. Under Running Status:
    • If the service is stopped, click the Start button to start the service.
    • If the service is started, click the Stop button to stop the service.
      Or click the Restart button to restart the service.
