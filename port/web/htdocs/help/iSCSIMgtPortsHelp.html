iSCSI Target Ports

The iSCSI Management–Port Target tab enables you to see the current Data Port settings.

To access to the iSCSI Management–Port Target tab:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administration Tools icon.
  3. Click the iSCSI Management icon.
  4. Click the Port Target tab in Management View.

Information

  • Controller ID – 1
  • Port ID – 1 or 2
  • Max Receive Data Segment Length – 8 KB is the default
  • Number of Active Sessions – Number of sessions logged into this port
  • Primary Header Digest Method – CRC-32
  • Primary Data Digest Method – CRC-32
  • iSCSI Receive Marker – None

Note: None of these values can be set by the User in the current version of the software.

Note: See also iSCSI Port Statistics.

A detailed explanation of these iSCSI functions, how and when they are used, and their relationship to one another is beyond the scope of this document. For more information, contact the Internet Engineering Task Force at http://www.ietf.org/.
