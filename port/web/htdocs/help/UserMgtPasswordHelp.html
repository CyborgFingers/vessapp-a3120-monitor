User Password

The User Management–Password tab enables you to change your password. The Administrator or a Super User can change another user's password.

To change your own password:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click on the User Management icon.
  4. Click on the Password tab in Management View.
  5. Enter the current password in the Old Password field.
  6. Enter the new password in the New Password field.
  7. Enter the new password in the Retype Password field.
  8. Click the Submit button.

To change another user's password:

  1. Log in as the Administrator or a Super User.
  2. Click the Subsystem icon in Tree View.
  3. Click the Administrative Tools icon.
  4. Click on the User Management icon.
  5. On the Information tab, click the User Name link of the user whose password you want to change.
  6. Click on the Password tab in Management View.
  7. Enter the new password in the New Password field.
  8. Enter the new password in the Retype Password field.
  9. Click the Submit button.
