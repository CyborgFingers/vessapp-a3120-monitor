UPS Settings

The UPS–Settings tab enables you to make management settings that control how the or subsystem detects the UPS unit and responds to data reported by the UPS.

To make UPS settings:

  1. Click the Subsystem icon in Tree view.
  2. Click the UPS icon.
  3. Click the Settings tab in Management View.

UPS Settings

Perform the following actions as required:

  • Verify the Current UPS Communication method. See Note 1:
    • SNMP - Network connection.
    • Serial - Serial connection.
    • Unknown - No connection.
  • Choose a Detection Setting from the dropdown menu:
    • Automatic - Default. If a UPS is detected when the subsystem boots, the setting changes to Enable.
    • Enable - Monitors UPS. Settings changes, reports warnings, and logs events.
    • Disable - Monitors UPS only.
  • Type values into the Threshold fields. See Note 2:
    • Running Time Remaining Threshold - Actual time below this value resets adaptive writeback cache to writethrough.
    • Warning Temperature Threshold - Actual temperature above this value triggers a warning and logs an event.
    • Loading Ratio Threshold - Actual loading ratio (percentage) above this threshold triggers a warning and logs an event. See Note 3.
    • Battery Charge Remaining Threshold - Reserve capacity below this percentage triggers a warning and logs an event.
  • For UPS units with network cards, type the IP addresses or DNS names in fields UPS 1 and UPS 2. See Note 4.

Click the Submit button to apply your settings.

Note 1: supports multiple UPS units using network or serial connections, but not a combination of both methods.
Note 2: Detection Setting must be set to Auto. If a UPS is detected, the setting changes to Enable.
Note 3: The maximum recommended Loading Ratio varies among models of UPS units. The general range is 60% to 80%.
Note 4: To specify UPS units by DNS names, ask your IT administrator to add the DNS names to the DNS server, before you make UPS settings.

UPS Settings

Perform the following actions as required:

  • Verify the Current UPS Communication method:
    • USB - USB connection.
    • Unknown - No connection.
  • Choose a Detection Setting from the dropdown menu:
    • Automatic - Default. If a UPS is detected when the subsystem boots, the setting changes to Enable.
    • Enable - Monitors UPS. Settings changes, reports warnings, and logs events.
    • Disable - Monitors UPS only.
  • Choose an Action Mode setting from the dropdown menu:
    • None - No additional action when Threshold value is exceeded.
    • ShutDown - Shuts down the subsystem when a Threshold value is exceeded.
  • Type values into the Threshold fields. See Note 1:
    • Running Time Remaining Threshold - Actual time below this value triggers the action set under Action Mode.
    • Warning Temperature Threshold - Actual temperature above this value triggers the action set under Action Mode.
    • Loading Ratio Threshold - Actual loading ratio (percentage) above this threshold triggers the action set under Action Mode. See Note 2.
    • Battery Charge Remaining Threshold - Reserve capacity below this percentage triggers a the action set under Action Mode.

Click the Submit button to apply your settings.

Note 1: Detection Setting must be set to Auto. If a UPS is detected, the setting changes to Enable.
Note 2: The maximum recommended Loading Ratio varies among models of UPS units. The general range is 60% to 80%.
