Subsystem Background Activities

The Subsystem–Background Activities tab provides information about functions that runs in the background on your subsystem. Click on the link below for information about the settings and options available for each feature.

  • Disk array Rebuilding
  • Disk array Synchronization
  • Logical Drive Initialization
  • Disk array Migration
  • Disk array Transition
  • Logical Drive Redundancy Check
  • Predictive Data Migration (PDM)
  • Error and Reassigned Block Thresholds (to trigger PDM. See Block Threshold Definitions, below)
  • Media Patrol

Also see Auto Rebuild.

To START a background activity:

  1. Click on the Subsystem icon in Tree View.
  2. From the dropdown menu on the Background Activities tab, choose the function you want to start.

To VIEW the background activities currently running or queued on your subsystem:

  1. Click on the Subsystem icon in Tree View.
  2. Click the Background Activities tab in Management View.
    Any currently running activities are listed under Background Activities.
  3. Click on the link for the activity you want to monitor, pause, resume, or stop.

To VIEW the current settings:

  1. Click on the Subsystem icon in Tree View.
  2. Click the Background Activities tab in Management View.

To CHANGE the current settings:

  1. Click on the Subsystem icon in Tree View.
  2. From the dropdown menu on the Background Activities tab, choose Settings.

For more information about individual settings, click on the individual activity links above.

Block Threshold Definitions:

  • Reassigned Block – When an error occurs in a physical drive, the directions to the block containing error are reassigned. When the number of reassigned blocks exceeds the threshold, PDM is triggered.
  • Error Block – When an error occurs in the data or the physical media in a disk drive, the block is marked and added to the block error count. When the number of error blocks exceeds the threshold, PDM is triggered.
