iSCSI Sessions

The iSCSI Management–Sessions tab lists the current iSCSI sessions on the Data Ports. The window displays a list of the current iSCSI sessions.

To access to the iSCSI Management–Sessions tab:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the iSCSI Management icon.
  4. Click the Sessions tab in Management View.
    The window displays a list of the current iSCSI sessions.
  5. Click on the Session Index link to display information about an individual session.

iSCSI Sessions

  • Index – iSCSI session index number.
  • Device Name – iSCSI initiator on the Host PC.
  • Port ID – ID number of the port on the iSCSI HBA card in the Host PC.
  • Device IP Address – IP Address of the port on iSCSI HBA card in the Host PC.
  • Status – Active. Inactive sessions are not listed.

A detailed explanation of these iSCSI functions, how and when they are used, and their relationship to one another is beyond the scope of this document. For more information, contact the Internet Engineering Task Force at http://www.ietf.org/.
