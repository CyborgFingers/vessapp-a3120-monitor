User Settings

The User Management–Settings tab enables you to view and change your display name and email address. The Administrator or a Super User can change another user's settings.

To change your own settings:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click on the User Management icon.
  4. Click on the Settings tab in Management View.
  5. Enter a display name in the Display Name field.
  6. Enter an email address in the Email field.
  7. Click the Submit button.

To change another user's settings:

  1. Log in as the Administrator or a Super User.
  2. Click the Subsystem icon in Tree View.
  3. Click the Administrative Tools icon.
  4. Click on the User Management icon.
  5. On the Information tab, click the User Name link of the user whose settings you want to change.
  6. Make the following settings as needed:
    • Check the Enable box to enable this user.
      Uncheck the box to disable this user.
    • Enter or change the display name.
    • Enter or change the email address.
    • From the Privilege dropdown menu, choose a new level.
      See the List of Privileges, below.
  7. Click the Submit button.

List of Privileges

  • View – Allows the user to see all status and settings but not to make any changes
  • Maintenance – Allows the user to perform maintenance tasks including Rebuilding, PDM, Media Patrol and Redundancy Check
  • Power – Allows the user to create (but not delete) disk arrays and logical drives, change RAID levels, change stripe size; change settings of components such as disk arrays, logical drives, physical drives and the controller.
  • Super – Allows the user full access to all functions including create and delete users and changing the settings of other users, and delete disk arrays and logical drives. The default "administrator" account is a Super User.
