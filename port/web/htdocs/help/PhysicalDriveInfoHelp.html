Physical Drive

The Physical Drive–Information tab provides information about the selected physical disk drive.

To view information about a physical drive:

  1. Click on the Subsytem icon in Tree View.
  2. Click on the Enclosures icon.
  3. Click on the Enclosure icon.
  4. Click on the Physical Drives icon.
  5. Click on a Physical Drive icon.
  6. From the dropdown menu on the Information tab, choose Statistics.

Physical Drive Information

This screen contains information about the physical drive:

  • Physical Drive ID – ID number.
  • Location – Enclosure number and Slot number.
  • Alias – If assigned.
  • Physical Capacity – Maximum capacity of the drive.
  • Configurable Capacity – Total useful capacity of the drive.
  • Used Capacity – Amount of the useful capacity that contains data.
  • Block Size – Size of the data blocks.
  • Operational Status – OK is normal. Can also show Rebuilding, Forced Offline, or Dead.
  • Configuration Status – The array to which the drive is assigned or its spare designation.
  • Model – Manufacturer model number.
  • Drive Interface – SATA, HDD or SSD.
  • Serial Number
  • Firmware Version
  • Protocol Version
  • Visible To – The controllers that can see this physical drive:
    • Fibre Channel subsytems with dual controllers and LUN Affinity enabled, Controller 1 or 2
    • Other configurations and subsystems, All Controllers

Advanced Physical Drive Information – SATA Drives

You can change the following items on the Physical Drives Global Settings tab:

  • Write Cache – Enabled or disabled.
  • Read Look Ahead Cache – Enabled or disabled.
  • Command Queuing – Enabled or disabled.
  • DMA Mode – Displays the mode in which the drive is running.
  • Medium Error Threshold – Number of bad blocks tolerated before the controller marks the drive as Dead.

Advanced Physical Drive Information – All Drives

  • SMART Feature Set – Supported or Not Supported.
  • SMART Self Test – Supported or Not Supported.
  • SMART Error Logging – Supported or Not Supported.
  • Command Queuing Support – NCQ or TCQ.
  • Queue Depth – Number of commands.
  • Maximum Multiple DMA Mode Supported
  • Maximum Ultra DMA Mode Supported
  • Drive Temperature
  • Drive Reference Temperature
  • APM Support – Advanced power management mode.

Locate a Physical Drive in the Enclosure

To locate a physical drive in the enclosure:

Click on the physical drives in the Enclosure Front View graphic.
The disk status LED will flash to identify the carrier holding the drive.
