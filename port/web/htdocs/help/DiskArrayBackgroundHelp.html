Disk Array Background Activity

The Disk Array–Background Activities tab provides information about functions that run in the background on your subsystem:

  • Disk array Migration
  • Disk array Rebuild
  • Predictive Data Migration (PDM)
  • Spare drive Transition

To START a background function:

  1. Click on the Subsystem icon in Tree View.
  2. Click on the Disk Arrays icon.
  3. Click on the Disk Array icon.
  4. From the dropdown menu on the Background Activities tab, choose the function you want to start.

To VIEW the progress of the current background activity and a list of activities in the queue:

  1. Click on the Subsystem icon in Tree View.
  2. Click the Background Activities tab in Management view.

To PAUSE, RESUME, or STOP an activity, under Background Activities, click on the link for that activity.

Note: Disk array migration does not allow you to pause, resume, or stop the activity once it begins.
