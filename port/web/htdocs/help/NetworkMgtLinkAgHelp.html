Network Management Link Aggregation

The Network Management–Link Aggregation tab enables you to see the current list of Link Aggregation entries. Aggregating the iSCSI data ports on your subsystem increases bandwidth.

To view the current Link Aggregation entries:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the Network Management icon.
  4. Click the Link Aggregation tab in Management View.

Link Aggregation entry information consists of:

  • Link Aggregation ID number
  • Master Port number
  • Slave Port number

To add a Link Aggregation, click the Link Aggregation tab dropdown menu and choose Create Link Aggregation Entry.

To change the settings of a Link Aggregation, click the ID link of the Link Aggregation you want to change.

To delete a Link Aggregation, click the Link Aggregation tab dropdown menu and choose Delete Link Aggregation Entry.
