Performance Monitoring

The Performance Monitoring–Information tab displays realtime performance statistics for:

  • Logical Drives
  • Physical Drives
  • Data Ports

In order to take advantage of this feature, there must be I/O data activity taking place on the subsystem.

The vertical scale adjusts dynamically to accommodate the statistical data.

To access Performance Monitoring:

  1. Click the Subsytem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the Information tab in Management View.
  4. Choose the component, devices, and measurement you want to monitor:
     
    • Logical Drives
      Devices, up to 4
      • All – The average of all logical drives
      • Individual logical drives
      Measurements
      • Bandwidth in MB/s
      • I/Os per second
      • Average Latency
      • Maximum Latency
      • Minimum Latency
      • % Used Cache – Percentage of the controller cache used.
      • % of Used Cache Dirty – Percentage of controller cache used by data that is not saved to disk.
         
    • Physical Drives
      Devices, up to 4
      • All – The average of all physical drives
      • Individual physical drives
      Measurements
      • Bandwidth in MB/s
      • I/Os per second
      • Average Latency
      • Maximum Latency
      • Minimum Latency
         
    • Data Ports
      Devices, up to 4
      • All – The average of all data ports
      • Individual data ports
      Measurements
      • Bandwidth in MB/s
      • I/Os per second
      • Average Latency
      • Maximum Latency
      • Minimum Latency
         

For a historical report of logical drive, physical drive, data port, and other statistics, see Subsystem Information.
