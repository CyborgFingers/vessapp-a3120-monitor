Delete a Link Aggregation

The Network Management–Link Aggregation tab enables you to delete a link aggregatation.

To delete a link aggregation entry:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the Network Management icon.
  4. In Management View, click the the Link Aggregation tab.
  5. In Management View, from the dropdown menu on the Link Aggregation tab, choose Delete Link Aggregation Entry.
  6. Check the box to the left of the Link Aggregation entry you want to delete.
  7. Click the Submit button.
