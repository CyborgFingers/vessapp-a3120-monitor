Create a Link Aggregation

The Network Management–Link Aggregation tab enables you to aggregate the iSCSI data ports on your subsystem to increase bandwidth.

If an iSCSI port is part of a VLAN, you must delete the VLAN entry before you can use the iSCSI port to create a link aggregation.

To create a link aggregation entry:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the Network Management icon.
  4. In Management View, from the dropdown menu on the Link Aggregation tab, choose Create Link Aggregation Entry.
  5. Enter a Trunk ID number.
    Use 1 to 32.
  6. From the Master Port dropdown menu, choose an iSCSI port number.
  7. From the Slave Port dropdown menu, choose the other iSCSI port number.
  8. Click the Submit button.
