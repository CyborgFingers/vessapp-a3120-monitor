Controller Statistics

The Controller–Information tab, Statistics dropdown menu provides statistical information about a specific subsystem controller. This information is useful for maintenance and troubleshooting.

To access Controller statistics:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Controllers icon.
  3. Click the Controller icon.
  4. Click on the Information tab in Management View and select Statistics from dropdown menu.

The Controller statistical information includes:

  • Data transferred (read and write)
  • Read Data transferred
  • Write Data transferred
  • Errors (total)
  • Non-read/write errors
  • Read errors
  • Write errors
  • I/O requests (total)
  • Non-read/write I/O requests
  • Read I/O requests
  • Write I/O requests
  • Statistics start time
  • Statistics collection time
