Enclosures

The Enclosures–Information tab provides component information about the subsystem enclosure, including:

  • Enclosure ID number
  • Enclosure Type ( model)
  • Operational Status – OK means normal operation
  • System Description – Everything is OK means normal operation
  • Locate – Click the button to locate the enclosure (see below)

To locate a subsystem enclosure:

  1. Click on the Subsytem icon in Tree View.
  2. Click on the Enclosures icon.
  3. Click on the Locate Enclosure button for the enclosure you want to locate.
    The Disk Status LEDs on the front of the enclosure will flash for one minute.
