Logical Drive Statistics

The Logical Drive–Information tab dropdown menu displays a list of statistics for the selected logical drive. This information is useful for maintenance and troubleshooting.

To view logical drive statistics:

  1. Click on the Subsystem icon in Tree View.
  2. Click on the Disk Arrays icon.
  3. Click on the Disk Array icon.
  4. Click on the Logical Drives icon.
  5. Click on the Logical Drive icon.
  6. From the dropdown menu on the Information tab, choose Statistics.

Statistical Information

  • Data Transferred (total)
  • Read Data Transferred
  • Write Data Transferred
  • Errors (total)
  • Non-Read/Write Errors
  • Read Errors
  • Write Errors
  • IO Requests (total)
  • Non-Read/Write IO Request
  • Read IO Request
  • Write IO Request
  • Statistics Start Date/Time
  • Statistics Collection Date/Time
