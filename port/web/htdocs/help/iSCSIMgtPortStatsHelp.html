iSCSI Port Statistics

The iSCSI Management–Port Targets tab, Port Statistics dropdown menu enables you to see the current Data Port statistics.

To access to the iSCSI Data Port statistics:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the iSCSI Management icon.
  4. Click the Port Target tab dropdown menu in Management View and choose Port Statistics.

Statistics

  • Controller ID – Controller ID.
  • Port ID – Controller Port ID.
  • MAC Counts
    Note: "macoctrxcnt" stands for Mac Octets Received Count
  • IP Statistics
  • TCP Statistics

A detailed explanation of these iSCSI functions, how and when they are used, and their relationship to one another is beyond the scope of this document. For more information, contact the Internet Engineering Task Force at http://www.ietf.org/.
