Fibre Channel SFP Information

The Fibre Channel Management–SFP tab enables you to view information about the SFPs (small form-factor pluggable transceivers) on each Fibre Channel port on the Controller, including:

  • Connector – Type of connector
  • Transceiver – SFP
  • Transceiver Code – Defines the method to interpret the transceiver type and compatibility options
  • Serial Encoding – Serial encoding algorithm
  • Bit Rate – In gigabits per second
  • Link Length – The maximum link length depending on the type of cable
  • Vendor Name – Vendor name of the SFP transceiver
  • Vendor OUI – Organizational Unique Idenfier, SFP vendor's IEEE company ID
  • Vendor Part Number
  • Vendor Revision
  • Vendor Serial Number
  • Manufacturing Date – Code with 2 digits each for year, month, day and optional vendor-specific lot number

There are no user settings on this tab.

From this point, you can link to Node Status, Port Status, Settings and Statistics; a list of Logged-in Devices and a list of Initiators.

To access this tab:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Fibre Channel Management icon.
  4. Click the SFP tab in Management View.
