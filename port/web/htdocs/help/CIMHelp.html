CIM

's CIM service provides a database for information about computer systems and network devices. This service is normally Stopped and set to Manual start.

To change the CIM startup settings:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the CIM Setting link in Management view.
  4. Under Startup Type:
    • Click on the Automatic option to start the service automatically during system startup.
    • Click on the Manual option to start the service manually (the service does not start during system startup).
  5. Click on the Submit button.

To change the CIM service settings:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the CIM Setting link in Management view.
  4. To use HTTP:
    • Click on the CIM HTTP Enabled option.
    • Enter the CIM HTTP Port number in the field provided.
      5988 is the default.
  5. To use HTTPS:
    • Click on the CIM HTTPS Enabled option.
    • Enter the CIM HTTP Port number in the field provided.
      5989 is the default.
  6. To use CIM Authentication, click on the CIM Authentication Yes option.
    Note: You cannot change the CIM User name.
  7. To change the CIM password, click on the Change Password Yes option.
    • Type the old password in the CIM User Old Password field.
    • Type the new password in the User New Password field.
    • Retype the new password in the Retype Password field.
  8. Click on the Submit button.
  9. Click the OK button in confirmation box to restart the CIM service.

To manually start, restart, or stop the CIM service:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the CIM Setting link in Management view.
  4. Click the button for the function you want:
    • Start – If the Running Status shows Stopped
    • Restart – If the Running Status shows Started
    • Stop – If the Running Status shows Started
  5. If you clicked Stop, click the OK button in the confirmation box.
