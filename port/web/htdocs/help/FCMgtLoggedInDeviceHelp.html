Fibre Channel Logged In Devices

The Fibre Channel Management–Logged In Device tab enables you to view information about the logged-in devices on the two Fibre Channel ports, including:

  • # – Device number
  • Port # – Port number
  • WWPN – World Wide Port Name
  • Port ID – ID of the device, not the Fibre Channel port
  • Symbolic Name – If used

One of the devices in the list for each port will be the port itself. If there is no other device, this notification will appear: There is no logged in device. If a Fibre Channel switch is attached, it will also appear in this list.

There are no user settings on this tab.

From this point, you can link to Node Status, Port Status, Settings and Statistics; SFP (transceiver) Status and a list of Initiators.

To access this tab:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Fibre Channel Management icon.
  4. Click the Logged In Device tab in Management View.
