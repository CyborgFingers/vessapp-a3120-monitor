RAID 60 Axles

When you create a RAID 60, you must specify the number of axles. An axle refers to a single RAID 6 array that is striped with other RAID 6 arrays to make RAID 60. A RAID 60 axle:

  • Can have four or more physical drives
  • Must have the same number of physical drives

RAID 60 also provides high reliability because data is still available even if multiple disk drives fail (one in each axle). The greater the number of axles, the greater the number of disk drives that can fail without the RAID 60 array going offline.

The chart below shows RAID 60 arrays with 8 to 16 disk drives, the available number of axles, and the resulting distribution of disk drives on each axle.
