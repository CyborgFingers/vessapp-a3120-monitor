Disk Arrays

The Disk Arrays–Information tab displays a list of disk arrays along with their status and capacity. A disk array is a collection of physical drives in a RAID. Logical drives are made from disk arrays.

  • Device – This is the unique ID number assigned to an individual disk array
  • Alias – A user-specified name for the disk array
  • Operational Status – OK, Synchronizing, Rebuilding, Degraded, Offline, Incomplate, or Transport Ready (see status)
  • Configurable Capacity – This is the data storage capacity available for new and existing logical drives
  • Free Capacity – This is the data storage capacity available for new logical drives

To create a new disk array, click the Create tab.
To delete an existing disk array, click the Delete tab.
To see more information about a specific disk array, click on its Device ID link.

To access the Disk Arrays–Information tab:

  1. Click on the Subsystem icon in Tree View.
  2. Click on the Disk Arrays icon.
