Subsystem Events

The Subsystem–Event tab provides information from the event (log) file of a specific subsystem. There are two classifications of events:

  • NVRAM Events – The most important events over multiple subsystem startups.
  • Runtime Events – The 1023 most recent events since the last subsystem startup.

Viewing Events

To view the event log for this subsystem:

  1. Click on the Subsystem in Tree View.
  2. From the dropdown menu on the Event tab, choose Runtime Events or Subsystem Events in NVRAM.
    If you just click on the Event tab, the Runtime Events are displayed.
  3. Click on the headings to sort the events.

The Event Frame displays events by:

  • Item Number – Sequencial number of the event
  • Device – The subsystem component that experienced the event
  • Event ID – A hexadecimal number
  • Severity:
    • Information – Information only, no action is required
    • Warning – User can decide whether or not action is required
    • Minor – Action is needed but the condition is not a serious at this time
    • Major – Action is needed now
    • Critical – Action is needed now and the implications of the condition are serious
    • Fatal – Non-Recoverable error or failure has occurred
  • Time and Date
  • Description

Sorting Events

You can sort the events by Item Number, Device, Event ID, Severity, Time and Date, or Description.

Click on the link at the top of the column by which you want to sort the events.
After you click on the item, a triangle icon appears.

  • If the triangle points upward, the column is sorted low-to-high or old-to-new.
  • If the triangle points downward, the column is sorted high-to-low or new-to-old.

Click the link a second time to change to flip the triangle and reverse the sort sequence.

Clearing Events

To clear the event file for this subsystem:

  1. Click on the Subsystem in Tree View.
  2. Click on the Event tab in Management View.
  3. Click on the Clear Event Log button.
  4. In the Confirmation dialog box, type the word confirm then click the OK button.

Saving Events to a File

To save the event file for this subsystem in a tab-delineated text file:

  1. Click on the Subsystem in Tree View.
  2. From the dropdown menu on the Event tab, choose Runtime Events or Subsystem Events in NVRAM.
  3. Click on the Save Event Log button.
    The next dialog boxes you see will vary depending on the browser and your browser settings.
    When the process is done, a file called "eventlog" is saved to the Host PC.

Note: You must save the Runtime Events log and Subsystem Events log as separate text files.
