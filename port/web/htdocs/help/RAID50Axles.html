RAID 50 Axles

When you create a RAID 50, you must specify the number of axles. An axle refers to a single RAID 5 array that is striped with other RAID 5 arrays to make RAID 50. A RAID 50 axle:

  • Can have three or more physical drives
  • Must have the same number of physical drives

RAID 50 also provides high reliability because data is still available even if multiple disk drives fail (one in each axle). The greater the number of axles, the greater the number of disk drives that can fail without the RAID 50 array going offline.
