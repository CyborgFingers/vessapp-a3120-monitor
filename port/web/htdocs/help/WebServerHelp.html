Web Server

's Web Server service connects to the subsystem though your browser.

To change the Web Server settings:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Web Server Setting link in Management view.
  4. Enter the HTTP Port number.
    8090 is the default.
  5. Enter Session Time Out interval.
    This setting causes to timeout after a period of inactivity.
    24 minutes is the default. The range is 1 to 1440 minutes (one day).
  6. If you want to use a secure connection, check the Enable SSL box.
  7. If you checked the Enable SSL box, enter a HTTPS Port number.
    8443 is the default.
  8. When you are done, click on the Submit button.
  9. Click OK in the confirmation box to restart the Web Server service with your changes.

To change the Web Server Automatic/Manual start setting:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Web Server Setting link in Management view.
  4. Under Startup Type:
    • Click on the Automatic option to start the service automatically during system startup.
    • Click on the Manual option to start the service manually (the service does not start during system startup).
  5. Click on the Submit button.

To manually start, restart, or stop the Web Server service:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Web Server Setting link in Management view.
  4. Under Running Status:
    • If the service is stopped, click the Start button to start the service.
    • If the service is started, click the Stop button to stop the service.
      Or click on the Restart button to restart the service.
