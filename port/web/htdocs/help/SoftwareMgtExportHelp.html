File Export

The Software Management–Export tab enables you to export a User Database or a Configuration Script from the subsystem to the Host PC.

User Databases – You can export the User Database file to the Host PC to transfer the Database to other s so that all have the same user information and settings.

Configuration Scripts – You can write a CLI configuration script to automatically configure your subsystem. The script must be a plain, non-encrypted text file. From there, you can import the script from the Host PC and perform the configuration automatically.
 
You can export the configuration script to the Host PC for modification or to transfer to another so that both subsystems have the same configuration and settings.

Caution: Do NOT attempt to write or modify a Configuration Script until you receive guidance from Technical Support.

To export the User Database or a Configuration Script from this subsystem:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administration Tools icon.
  3. Click the Export link in Management View.
  4. Click the Export button.
  5. In the Opening export dialog box, click the Save to Disk option.
  6. Click the OK button.
    The user database or configuration script file is saved to the Host PC from which you access .

Note: The Encryption box is grayed out. Encryption is always enabled.
