Controller

The Controller–Information tab provides information about a specific subsystem controller. This information is useful for maintenance and troubleshooting.

To access Controller information:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Controllers icon.
  3. Click on the Controller icon.
  4. Click on the Information tab in Management View.

The Controller information includes:

  • Controller ID
  • Alias, if assigned*
  • Operational Status
  • Power On Time
  • Cache Usage (percent)
  • Dirty Cache Usage (percent) – Refers to data in the cache that is not yet saved to a physical drive
  • Part number
  • Serial number
  • Hardware Revision number
  • WWN – World Wide Number of the controller
  • SCSI Protocols supported
  • Boot Loader Version
  • Boot Loader Build Date
  • Firmware Version number
  • Firmware Build Date
  • Software Version number
  • Software Build Date

The Advanced Controller information includes:

  • Memory Type – Controller's data cache.
  • Memory Size
  • Flash Type – Stores firmware, software and user configurations.
  • Flash Size
  • Preferred Cache Line Size
  • Cache Line Size
  • Coercion* – See Capacity Coercion.
  • Coercion Method* – See Capacity Coercion.
  • SMART* – Self-Monitoring, Analysis and Reporting System for physical drives
  • SMART Polling Interval*
  • Write Back Cache Flush Interval*
  • Enclosure Polling interval*
  • Host Cache Flushing*
  • Forced Read Ahead (cache)*
  • Physical Drive Temperature Threshold*
  • Physical Drive Critical Temperature Threshold*
