File Import

The Software Management–Import tab enables you to import a User Database file or a Configuration Script file from the Host PC to the subsystem. As part of this function, the automatically applies the user information and settings, or the configuration and settings, from the imported file.

User Databases – When you make user settings to one , you can export the the User Database file to the Host PC. From there, you can import the User Database file to other s so that all have the same User information and settings.

Configuration Scripts – You can write a CLI configuration script to automatically configure your subsystem. The script must be a plain, non-encrypted text file. From there, you can import the script from the Host PC and perform the configuration automatically.
 
You can also import a configuration script that was exported from another , so that both subsystems have the same configuration.

Cautions:

  • Do NOT attempt to write or modify a Configuration Script until you receive guidance from Technical Support.
  • Importing a user database or configuration script will overwrite the current settings on your subsystem.

To import a User Database or Configuration Script to this subsystem:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administration Tools icon.
  3. Click the Import link in Management view.
  4. Choose the type of file from the Type dropdown menu.
    User Database or Configuration Script.
  5. Enter the name of the file to be imported.
    Or, click the Browse... button to search for the file.
  6. Click the Submit button.
  7. Click the Next button.
    If the imported file is a valid, a warning informs you that the database or script will overwrite your current settings.
  8. Click the OK button.
    This user settings or configuration are applied to this subsystem.
