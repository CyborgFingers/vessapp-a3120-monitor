Physical Drives Global Settings

The Physical Drives–Global Settings tab enables you to make settings that apply to all of the physical disk drives installed in the subsystem enclosure.

To make settings for all physical drives:

  1. Click the Subsytem icon in Tree View.
  2. Click the Enclosures icon.
  3. Click the Enclosure icon.
  4. Click the Physical Drives icon.
  5. Click the Global Settings tab in Management View.
  6. Make the following settings as needed.

    For SATA drives, check the boxes to enable:
    • Write Cache
    • Read Look Ahead Cache
    • Command Queuing (for disk drives that support Command Queuing)
    • From the DMA Mode dropdown menu, select the DMA mode.
      UDMA5 is the default.

    Type a number in the Medium Error Threshold field. See the Note below.

  7. Click the Submit button.

Note: Medium Error Threshold is the number of bad blocks tolerated before the controller marks the drive as Dead.

  • The maximum mumber of bad blocks is 4,294,967,294.
  • The default setting of zero blocks disables this function.
  • With the Threshold set to zero, drives are not marked Dead even when errors are detected.
