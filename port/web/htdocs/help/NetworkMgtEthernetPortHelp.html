Network Management Port Settings

To make changes to the Management Port settings:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Network Management icon.
  4. Click the Port 1 link in Management View.
  5. To enable DHCP, check the DHCP box.
  6. When DHCP is NOT enabled, enter the following:
    • Primary IP address
    • Primary subnet mask
    • Default gateway IP address
  7. Enter a primary DNS server IP address.
  8. Click the Submit button.

Note: For iSCSI network settings on the Data Ports, click on the iSCSI Network tab.
