Firmware Image Version

The Software Management–Image Version tab enables you view the package of firmware components on the controller or controllers. The components are displayed by enclosure. The enclosures are listed in Tree View.

Enclosure image version information includes:

  • Image Condition – Running or Flashed.
    If the Running and Flashed image version numbers do not match, the was not restarted since the firmware was last updated. Restart the to run the Flashed firmware package.
  • Image Type – A component of the firmware package.
    RAID subsystems use:
    • Redboot ROM
    • Kernel
    • Firmware
    • Software
    • Ramdisk
    • SEP Firmware
    • Redboot RAM
    • OEM Customization
  • Controller ID – 1 or 2.
  • Version – Version number of the component.
  • Build Date – Build date of the component. Older versions might show N/A.
  • Flash Date – Flash or installation date of the component. Older versions might show N/A.

To view image version information:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administrative Tools icon.
  3. Click the Software Management icon.
  4. Click the Image Version tab.
    The image version information displays on the screen.
