Controller Problems

When a RAID controller encounters an internal problem, it can enter maintenance mode. When an controller enters maintenance mode, it goes offline and it displays Missing under Operational Status.

Note that subsystems with only one controller will always show that the second controller is Missing.
For s with two controllers, one of the controllers will display Missing if a controller is improperly configured or it has been removed from the subsystem.
Before proceeding, be sure that both controllers:

  • Have the same Firmware version
  • Have the same amount of SDRAM
  • Are properly installed and connected

To obtain this information for a controller, click on the Controller icon, Information tab, and look for Firmware Version and Memory Size.

To access a controller in maintenance mode, use a serial connection. See Chapter 2 of the Product Manual for instructions.
Or, if you know the controller’s IP address, you can access the controller using a Telnet connection.
See Chapter 6 of the Product Manual for more information about updating the firmware using a TFTP server over a Telnet connection.

Also see Adding a Second Controller.
