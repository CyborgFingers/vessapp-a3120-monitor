Fibre Channel Initiators

The Fibre Channel Management–Initiator tab enables you to view information about the initiators on the two Fibre Channel ports on the Controller. You must add an initiator to the 's initiator list in order to use the initiator to create a LUN for your logical drive.

  • # – Device number
  • WWPN – World Wide Port Name
  • Port ID – ID of the initiator, not the Fibre Channel port
  • Symbolic Name – If used

Note: A Fibre Channel switch will also display as an initiator in the list.

Note: If your Host PC's Fibre Channel HBA is connected to the directly (not though a Fibre Channel switch), the initiator will NOT display in the initiator list.

From this point, you can link to Node Status, Port Status, Settings and Statistics; SFP (transceiver) Status and a list of Logged-in Devices.

To view a list of recognized initiators:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the Fibre Channel Management icon.
  4. In the Management window, click the Initiators tab.
    A list of all currently recognized initiators appears the screen.

To add an initiator to the 's initiator list:

  1. Check the box to the left of the initiator.
  2. Click the Add to Initiator List button.

The initiator appears under Storage Services. You can then use the initiator to create a LUN.
