Fibre Channel Statistics

The Fibre Channel Management–Statistic tab enables you to view statistics of the Fibre Channel ports on the Controller, including:

  • Time since last reset
  • Number of frames sent
  • Number of frames received
  • Number of words sent
  • Number of words received
  • LIP Count – Loop initialization primitive count
  • NOS Count – Not operational primitive sequence count
  • Number of error frames
  • Number of dumped frames
  • Link Failure Count
  • Loss Sync Count
  • Loss Signal Count
  • Primitive Sequence Error Count
  • Invalid Word Sent Count
  • Invalid CRC Count
  • Initiator IO Count

There are no user settings on this tab.

From this point, you can link to Node Status, Port Status and Settings; SFP (transceiver) Status, a list of Logged-in Devices and a list of Initiators.

To access this tab:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Fibre Channel Management icon.
  4. Click the Statistic tab in Management View.
