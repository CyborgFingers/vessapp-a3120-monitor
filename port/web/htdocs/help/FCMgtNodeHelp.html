Fibre Channel Node

The Fibre Channel Management–Node tab enables you to see information about the Fibre Channel node on the Controller, including:

  • WWNN – World Wide Node Name
  • Supported Features – Class of service
  • Maximum Frame Size – 2048 bits
  • Supported Speeds – 4 Gb/s, 2Gb/s, or 1 Gb/s

There are no user settings on this screen.

From this point, you can link to Port Status, Settings and Statistics; SFP (transceiver) Status, a list of Logged-in Devices and a list of Initiators.

To access this tab:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Fibre Channel Management icon.
  4. Click the Node tab in Management View.
