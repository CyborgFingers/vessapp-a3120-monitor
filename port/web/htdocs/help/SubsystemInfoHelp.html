Subsystem

The Subsystem–Information tab provides information about a specific subsystem.
subsystems are identified in the Tree by its Management Port IP address.

To save a System Service Report as a text file on your Host PC, click the Save button.

To set an alias for this subsystem lick the Settings tab.

To review the event log, click the Event tab.

To review and change settings for:

  • Rebuild
  • Auto Rebuild
  • Synchronization
  • Initialization
  • Redundancy Check
  • Migration
  • PDM
  • Transition
  • Media Patrol

Click the Background Activities tab.

To review and set the schedules for:

  • Media Patrol
  • Redundancy Check
  • Spare Check

Click the Scheduler tab.

To lock this subsystem, click the Lock tab.
