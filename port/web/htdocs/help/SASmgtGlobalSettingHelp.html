SAS Port Settings

The SAS Managment Global Settings tab enables you to apply the Narrow Port feature to the SAS ports on the subsystem.
A Narrow Port communicates over a narrow link and contains only one transmit/receive pair. This configuration can increase video server performance.

To make global settings to the SAS ports:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the SAS Management icon.
  4. Click the Global Settings tab in Management View.
  5. Check the Enable Narrow Port box to enable the Narrow Port feature.
    Uncheck the box to disable the feature.
  6. Click the Submit button.
