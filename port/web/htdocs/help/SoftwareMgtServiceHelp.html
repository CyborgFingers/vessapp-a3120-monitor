Software Services

The Software Management–Services tab provides a list of software services and links to the settings for each. A Service is process in the operating system that enables a specific functionality and runs in the background.

You can set a Service to start automaticallly when the boots. Or you can start the Service manually when you need its particular function. On this tab you can set a service to start automatically or you can start, restart or stop a service manually. The services are:

  • Email
  • Service Location Protocol (SLP)
  • Web Server
  • Telnet

By default, all of these Services start automatically, which is set to start manually. The default settings are best for most applications.

To change a Automatic/Manual start setting:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administration Tools icon.
  3. Click the Software Management icon.
    A list of software services appears in Management View.
  4. Click the Service Name you want.
  5. Under Startup Type:
    • Click the Automatic option to start the service automatically during system startup.
    • Click the Manual option to start the service manually (the service does not start during system startup).
  6. Click the Submit button.

To manually start, restart or stop a Service:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administration Tools icon.
  3. Click the Software Management icon.
    A list of software services appears in Management View.
  4. Click the Service Name you want.
  5. Under Running Status:
    • If the service is stopped, click the Start button to start the service.
    • If the service is started, click the Stop button to stop the service.
      Or click the Restart button to restart the service.
