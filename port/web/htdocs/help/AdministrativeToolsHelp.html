Administrative Tools

The Administrative Tools list provides links to a variety of important functions, including:

  • User Management – User Management where you can create or delete users, passwords, event subscriptions, etc.
  • Network Management – Network settings for 's Management and Data ports
  • Export File – Software Management Export File function
  • Import File – Software Management Import File function
  • Restore Factory Defaults – A list of items you can select and reset to default value
  • Performance Monitoring – Realtime performance statistics for logical drives, physical drives, and data ports
  • Clear Statistics – Clears statistical data on controllers, physical drives and logical drives
  • Save System Service Report – Goes to the Subsystem Information tab where you can save a System Service Report to your Host PC
