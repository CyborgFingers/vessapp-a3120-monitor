RAID 30 Axles

Note that only subsystems currently support RAID 3 and RAID 30.

When you create a RAID 30, you must specify the number of axles. An axle refers to a single RAID 3 array that is striped with other RAID 3 arrays to make RAID 30. A RAID 30 axle can have from 3 to 16 physical drives.

RAID 30 also provides high reliability because data is still available even if multiple disk drives fail (one in each axle). The greater the number of axles, the greater the number of disk drives that can fail without the RAID 30 array going offline.
