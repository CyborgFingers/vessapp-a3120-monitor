Network Management Port Configuration

subsystems have a virtual management port. When you log into the over your network, you use the virtual management port. This arrangement enables you to log into a with two controllers using one IP address.

subsystems have a physical management port on a single controller using one IP address.

To make Subsystem Management Port settings:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the Network Management icon.
  4. On the Management Port tab, click the Port Configuration link.
  5. To enable DHCP, check the DHCP box.
    When DHCP is not enabled, enter:
    • Primary IP address
    • Primary subnet mask
    • Default gateway IP address
    • Enter a primary DNS server IP address
  6. subsystems only: To enable Wake on LAN, check the Wake on LAN box.
  7. Click the Submit button.

Important: If you choose to enable DHCP, have your Network Administrator dedicate an IP address for the , linked to the ’s MAC address. See Chapter 3 of the Product Manual for more information.
