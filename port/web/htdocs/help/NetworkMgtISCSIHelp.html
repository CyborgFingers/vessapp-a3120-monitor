Network Management iSCSI Ports

The Network Management–iSCSI Ports tab enables you to see the current Data Port settings on the Controller.

To view the current iSCSI Port information and settings:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the Network Management icon.
  4. Click the iSCSI Ports tab in Management View.

iSCSI data port information and settings consist of:

  • Controller ID
  • Maximum number of ports supported
  • Number of ports present
  • Number of failed ports
  • Port ID
  • Port status (enabled or disabled)
  • Link status (up or down)
  • IP type
  • DHCP status (enabled or disabled)
  • Primary IP address
  • Primary subnet mask
  • Default gateway IP address
  • Primary MAC address
  • Maximum speed supported by this connection
  • Jumbo Frames (enabled or disabled)
  • TCP port number (3260 is the default)

iSCSI data port information and settings consist of:

To make changes to the Data Port settings, click the Port Configuration link for the data port you want.

Note: For network settings on the Management Ports, click on the Management Port tab.
