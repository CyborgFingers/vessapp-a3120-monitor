Network Management Maintenance Mode Configuration

The controller has an IP addresses for access when the controller goes into maintenance mode. Maintenance mode is only for remedial action in the event of a problem with the controller. For more information, see Controller Problems.

To make Maintenance Mode settings:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the Network Management icon.
    The current Management Port settings appear in the Management window.
  4. Click one of the Port Configuration links.
  5. To enable DHCP, check the DHCP box.
    When DHCP is not enabled, enter:
    • Primary IP address
    • Primary subnet mask
    • Default gateway IP address
    • Enter a primary DNS server IP address
  6. Click the Submit button.
  7. Click the Maintenance Mode tab again.
  8. Click the Port Configuration link for the other controller.
  9. To enable DHCP, check the DHCP box.
    When DHCP is not enabled, enter:
    • Primary IP address
    • Primary subnet mask
    • Default gateway IP address
    • Enter a primary DNS server IP address
  10. Click the Submit button.
