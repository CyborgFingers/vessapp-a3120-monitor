Redundancy Check

Redundancy Check is a routine maintenance procedure for fault-tolerant disk arrays (those with redundancy) that ensures all the data matches exactly. Redundancy Check can also correct inconsistencies.

Redundancy Check a Logical Drive

  1. Click on the Subsytem icon in Tree View.
  2. Click on the Logical Drive Summary icon.
  3. Click on the icon of the logical drive you want to Redundancy Check.
  4. From the dropdown menu on the Background Activities tab, select Redundancy Check.
  5. To select Auto Fix, check the box.
    This feature attempts to repair the problem when it finds an error.
  6. To select Pause On Error, check the box.
    This feature stops the process when it finds an error.
    If Auto Fix is also checked, the process stops only when it finds a non-repairable error.
  7. Click the Submit button.

The Background Activities tab displays the progress of the Redundancy Check.

Note: You can also start Redundancy Check from the Subsystem icon Background Activities tab.

Pause, Resume, or Stop a Redundancy Check

To pause, resume, or stop the Redundancy Check:

  1. Click on the Subsytem icon in Tree View.
  2. Click on the Logical Drive Summary icon.
  3. Click on the icon of the logical drive under Redundancy Check.
  4. Click on the Background Activities tab in Management view.
  5. Under Background Activities, click on the Redundancy Check link.

Note: You can also pause, resume, or stop the Initialization from the Subsystem icon Background Activities tab.

Set Redundancy Check Priority

  1. Click on the Subsytem icon in Tree View.
  2. From the dropdown menu on the Background Activities tab, select Settings.
  3. Click on the Redundancy Check Rate dropdown menu and select a rate: Low, Medium or High.
    • Low allocates fewer system resources to the Redundancy Check and more to data read/write operations.
    • Medium allocates a balance of system resources to the Redundancy Check and data read/write operations.
    • High allocates more system resources to the Redundancy Check and fewer to data read/write operations.
  4. Click on the Submit button.
