Rebuild Disk Array

When you rebuild a disk array, you are actually rebuilding the data on one physical drive.

  • When a physical drive in a disk array fails and a spare drive of adequate capacity is available, the disk array will begin to rebuild automatically using the spare drive.
  • If there is no spare drive of adequate capacity, but the Auto Rebuild function is ENABLED, the disk array will begin to rebuild automatically as soon as you remove the failed physical drive and install an unconfigured physical drive in the same slot.
  • If there is no spare drive of adequate capacity and the Auto Rebuild function is DISABLED, you must replace the failed drive with an unconfigured physical drive, then perform a Manual Rebuild.

Also see Logical Drive Degraded.

Important: If your replacement disk drive was formerly part of a different disk array or logical drive, you must clear the configuration data on the replacement drive before you use it.

Enable Auto Rebuild

  1. Click on the Subsytem icon in Tree View.
  2. Click on the Background Activities tab in Management View.
  3. From the Background Activities dropdown menu, select Settings.
  4. Check the Auto Rebuild Enabled box.
  5. Click on the Submit button.

Manual Rebuild

To perform a disk array manual rebuild:

  1. Click on the Subsytem icon in Tree View.
  2. Click on the Disk Arrays icon.
  3. Click on the Disk Array icon.
    If there are multiple disk arrays, choose the icon with the yellow !.
  4. From the dropdown menu on the Backgound Activities tab, select Start Rebuild.
  5. Select the Source physical drive.
    This is a remaining functional physical drive in the disk array.
  6. Select the Target physical drive.
    This is the replacement physical drive.
  7. Click the Submit button.

Click on the Disk Array Background Activities tab displays the progress of the rebuild.
Depending on the size of the physical disk involved, this process will take some time.

Note: You can also start a Manual Rebuild from the Subsystem icon Background Activities tab.

Pause, Resume, or Stop the Rebuild

To pause, resume, or stop the Rebuild:

  1. Click on the Subsytem icon in Tree View.
  2. Click on the Disk Arrays icon.
  3. Click on the Disk Array icon.
  4. Click on the Background Activities tab in Management view.
  5. Under Background Activities, click on the Rebuild link.

Note: You can also pause, resume, or stop the Rebuild from the Subsystem icon Background Activities tab.

Set Rebuild Priority

Rebuild priority applies to all disk array rebuilds whether they use a spare drive, the Auto Rebuild function or a manual rebuild procedure.

  1. Click on the Subsytem icon in Tree View.
  2. From the dropdown menu on the Background Activities tab, select Settings.
  3. Click on the Rebuild Rate dropdown menu and select a rate: Low, Medium or High.
    • Low allocates fewer system resources to the Rebuild Rate and more to data read/write operations.
    • Medium allocates a balance of system resources to the Rebuild Rate and data read/write operations.
    • High allocates more system resources to the Rebuild Rate and fewer to data read/write operations.
  4. Click on the Auto Rebuild Enabled box to enable Auto Rebuild.
  5. Click on the Submit button.
