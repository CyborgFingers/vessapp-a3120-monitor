Fibre Channel Port Settings

The Fibre Channel Management–Port tab enables you to make Data Port settings on the Controller, including:

  • Configured Link Speed – 4 Gb/s, 2 Gb/s, 1 Gb/s, or Auto
  • Configured Topology – NL Port, N-Port or Auto
  • Hard ALPA – Address can be 0 to 254. 255 means this feature is disabled. An ALPA identifies a port in an arbitrated loop.

From this point, you can link to Node Status, Port Status and Statistics; SFP (transceiver) Status, a list of Logged-in Devices and a list of Initiators.

To change Port settings:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the Fibre Channel Management icon.
  4. Click the Port tab in Management View.
  5. Click the Port1 or Port2 link in Management View.
  6. Make the following settings as needed:
    • From the Configured Link Speed dropdown menu, choose a link speed.
    • From the Configured Topology dropdown menu, choose a topology.
      See the table below for which topology to select.
    • In the Hard ALPA field, type a Hard ALPA address.
  7. Click the Submit button.
  8. In the confirmation box, type the word confirm in the field provided.
  9. Click the OK button.

The table below shows the type of attached topology you will achieve based on your connection type and the configured topology you select:

Fibre Channel Attached Topology
  Configured Topology
Connection Type N-Port NL-Port
Switch Fabric Direct Public Loop
Direct Point to Point Private Loop

Example 1: If you connect the to a Fibre Channel switch and select NL-Port topology, you will create a Public Loop attached topology.

Example 2: If you connect the to a Fibre Channel HBA card, and select N-Port, you will create a Point to Point attached topology.

Note: In some cases, HBA settings to N-Port only work if connected to the switch. Refer to your HBA manual for more information.
