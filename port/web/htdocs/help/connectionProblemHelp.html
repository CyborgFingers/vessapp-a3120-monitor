Connection Problems

When you install your following the instructions in the Quick Start Guide (printed) and Product Manual (on the Software CD), you should have little trouble getting your equipment to work the first time. But connection problems can arise that are not the User's or Installer's fault. Nor can every conceivable problem be covered in the documentation.

Connection problems cause a majority of failures in almost any electrical system. While the installation of the cables and components was correct, they do not function properly, or at all, because:

  • A connector is dirty or corroded

  • A connector is loose or damaged

  • A cable looks OK outside but has an open circuit inside

  • The wrong cable was used

Serial Connections

uses a serial connection for a command line utility (CLU). Normally, users prefer because of its graphic user interface. But the CLU can do the same jobs. And it will work when your network connection is down.

For , you must use the CLU to set the Management Port IP address in order for to connect with it. This issue is discussed further under Network Connections (below). See the Quick Start Guide or Chapter 2 of the Product Manual for more information on setup and connections.

The CLU controls and manages but it does not move data. It communicates through a null-modem cable, supplied with the . A straight-through serial cable will not work for this purpose. You probably will not use the CLU often and want to disconnect and store the cable. Consider leaving it connected, to be sure it will be there when you need it.

Network Connections

has an RJ-45 Management Port connector on the back of its cabinet. This is a Gigabit Ethernet connector designed to connect to your network. The becomes a node on your network like any other PC, server or other component with an IP address. ships from the factory an IP address of 10.0.0.2. You must change this address to one that will work with your network. You make the initial IP address setting using the CLU, as mentioned above. You can make subsequent IP address changes using the Graphic User Interface (GUI).

Note that Management Port can accept IP address assignments from a DHCP server. Use 's Command Line Utility (CLU) to enable this feature. If you have not activated DHCP support but there is a DHCP server on your network, there is a chance that it will inadvertently assign the 's Management Port IP address to another node. You might see a warning to this effect on your PC's monitor. If this happens, may not be able to connect. See your network administrator to work out a suitable arrangement.
