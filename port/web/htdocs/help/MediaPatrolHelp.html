Media Patrol

Media Patrol is a routine maintenance procedure that checks the magnetic media on each disk drive. Media Patrol checks all physical drives assigned to disk arrays. Media Patrol does not check unconfigured drives.

Media Patrol will also check spare drives, if those drives have Media Patrol enabled. Media Patrol for spare drives is enabled by default. You can disable it in 's Command Line Interface (CLI).

Unlike Synchronization and Redundancy Check, Media Patrol is concerned with the condition of the media itself, not the data recorded on the media. If Media Patrol encounters a critical error, it triggers PDM if PDM is enabled.

Run Media Patrol

To run Media Patrol, take the following actions:

  1. Click on the Subsytem icon in Tree View.
  2. From the dropdown menu on the Background Activities tab, select Start Media Patrol.
  3. Click the Start button.

The Media Patrol Status window displays while PDM checks your disk arrays, you will have full access to your logical drives.

Pause, Resume, or Stop Media Patrol

To pause, resume, or stop Media Patrol:

  1. Click on the Subsytem icon in Tree View.
  2. Click on the Background Activities tab in Management view.
  3. Under Background Activities, click on the Media Patrol link.

Set Media Patrol Priority

  1. Click on the Subsytem icon in Tree View.
  2. From the dropdown menu on the Background Activities tab, select Settings.
  3. Click on the Media Patrol Rate dropdown menu and select a rate: Low, Medium or High.
    • Low allocates fewer system resources to the Media Patrol and more to data read/write operations.
    • Medium allocates a balance of system resources to the Media Patrol and data read/write operations.
    • High allocates more system resources to the Media Patrol and fewer to data read/write operations.
  4. Click on the Submit button.
