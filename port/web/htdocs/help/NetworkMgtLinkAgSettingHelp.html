Change Link Aggregation Settings

The Network Management–Link Aggregation tab enables you to change the settings of a link aggregatation.

To change the settings of a link aggregation entry:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click the Network Management icon.
  4. In Management View, click the the Link Aggregation tab.
  5. Click the ID link of the link aggregation you want to change.
  6. From the Master Port dropdown menu, choose an iSCSI port number.
  7. From the Slave Port dropdown menu, choose the other iSCSI port number.
  8. Click the Submit button.
