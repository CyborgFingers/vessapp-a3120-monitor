iSCSI iSNS

The iSCSI Management–iSNS tab enables you to view and change the current Internet Storage Name Service (iSNS) settings on the Controller data ports.

A detailed explanation of these iSCSI functions, how and when they are used, and their relationship to one another is beyond the scope of this document. For more information, contact the Internet Engineering Task Force at http://www.ietf.org/.

Note: Edge Side Includes (ESI) is a markup language that enables dynamic assembly of web page elements in servers across a network. This feature enables automatically if iSNS is enabled and an iSNS server is present.

To make changes to the iSNS settings:

  1. Click on the Subsystem icon in Tree view.
  2. Click on the Administration Tools icon.
  3. Click on the iSCSI Management icon.
  4. Click on the iSNS tab in Management View.
  5. Click the iSNS link.
  6. Check the box to enable iSNS.
  7. Enter the iSNS server IP address.
  8. Enter a new iSNS Port number if required.
    The range is 1 to 65535.
  9. Click the Submit button.
