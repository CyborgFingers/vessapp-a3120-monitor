Network Management iSCSI Port Settings

To make changes to the Data Port settings:

  1. Click the Subsystem icon in Tree view.
  2. Click the Administration Tools icon.
  3. Click the Network Management icon.
  4. Click the iSCSI Ports tab in Management View.
  5. Click the Port Configuration link for the iSCSI data port you want.
  6. To enable DHCP, check the DHCP box.
  7. When DHCP is NOT enabled, enter the following:
    • Primary IP address
    • Primary subnet mask
    • Default gateway IP address
  8. To enable jumbo frames, check the Jumbo Frame box.
  9. Enter a TCP port number (3260 is the default).
  10. Click the Submit button.

Note: For iSCSI management settings on the Data Ports, click on the iSCSI Management icon in Tree View.
