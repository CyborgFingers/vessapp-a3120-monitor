Disk Array Migration

For , the term "Disk Array Migration" means either or both of the following:

  • Change the RAID Level of a logical drive
  • Expand the storage capacity of a logical drive

Before you begin a migration, examine your current disk array to determine whether:

  • The physical drives in your array can support the target RAID Level
  • There is sufficient capacity to accommodate the target logical drive size

If you need to add physical drives to your array, be sure there are unassigned physical drives are installed in your subsystem before you begin migration.

To Migrate an existing disk array:

  1. Click on the Subsystem icon in Tree View.
  2. Click on the Disk Arrays icon.
  3. Click on the Disk Array icon.
  4. From the dropdown menu on the Background Activities tab, select Start Migration.
  5. Highlight physical drives you want in the disk array from the Available list and press the >> button to move them to the Selected list.
    You can also double-click them to move them.
  6. When you are done, click the Next button.
  7. Select a new RAID Level, if desired.
  8. To expand the capacity of one or more logical drives, check the Expand Capacity box.
  9. If you checked the Expand Capacity box, enter a number into the Capacity field and select the appropriate unit of measure (MB, GB, TB).
  10. Under Capacity Usage, highlight the logical drive whose RAID level you want to change or whose capacity you want to expand.
  11. Click on the Update button.
    The logical drive changes to reflect your choices.
  12. Update other logical drives using the same method.
  13. When you are done making the changes, click on the Next button.
  14. Click on the Submit button to begin Migration.

The Disk Array Background Activities tab displays the progress of the Migration.
Click on the Migration link under Background Activities for more information.

Note: If you add an odd number of physical drives to a RAID 10 array, it will become a RAID 1E array by default.

Set Migration Priority

You can specify the Migration priority setting, which affect how quickly the migrates your Disk Array and how it responds to data read/write operations. To view or change the Migration priority setting:

  1. Click on the Subsystem icon in Tree View.
  2. From the dropdown menu on the Background Activities tab, choose Settings.
  3. Click on the Migration Rate dropdown menu and select a rate: Low, Medium or High.
    • Low allocates fewer system resources to the Migration and more to data read/write operations.
    • Medium allocates a balance of system resources to the Migration and data read/write operations.
    • High allocates more system resources to the Migration and fewer to data read/write operations.
  4. Click on the Submit button.
