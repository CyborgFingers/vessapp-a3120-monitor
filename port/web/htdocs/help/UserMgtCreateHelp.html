Create a User

The User Management–Create tab enables the Administrator or a Super User to create other users. To create a user:

  1. Click the Subsystem icon in Tree View.
  2. Click the Administrative Tools icon.
  3. Click on the User Management icon.
  4. Click on the Create tab in Management View.
  5. Enter a user name in the User Name field.
  6. Enter a password in the New Password field. See note below.
  7. Enter the password in the Retype Password field.
  8. Enter a display name in the Display Name field. See note below.
  9. Enter the user's email address in the Email field. See note below.
  10. Select a privilege level from the Privilege dropdown menu.
    For definitions of each privilege level, see the list below.
  11. Check the Enable box to enable this user on this subsystem.
  12. Click the Submit button.

Note: A password is optional. If you do not specify a password, log into with the User Name and leave the password field blank.

Note: A display name is optional.

Note: An email address is optional. However, you must specify an email address in order to receive email event notification.

List of Privileges

  • View – Allows the user to see all status and settings but not to make any changes
  • Maintenance – Allows the user to perform maintenance tasks including Rebuilding, PDM, Media Patrol and Redundancy Check
  • Power – Allows the user to create (but not delete) disk arrays and logical drives, change RAID levels, change stripe size; change settings of components such as disk arrays, logical drives, physical drives and the controller.
  • Super – Allows the user full access to all functions including create and delete users and changing the settings of other users, and delete disk arrays and logical drives. The default "administrator" account is a Super User.

Note: Each user can select his/her password under the User Management–Password tab.
