Delete a Disk Array

The Disk Arrays–Delete tab enables you to delete existing disk arrays.

Caution: If you delete a disk array, you also delete any logical drives that belong to it, along with the data in those logical drives. Back up any important data before deleting a disk array.

To delete a disk array:

  1. Click on the Subsystem icon in Tree View.
  2. Click on the Disk Arrays icon.
  3. Click on the Delete tab in Management View.
  4. Check the box to the left of the disk array you want to delete.
  5. Click the Submit button.
  6. In the confirmation box, type the word confirm in the field provided.
  7. Click the OK button.

The selected disk array disappears from the Disk Array List on the Information tab.
