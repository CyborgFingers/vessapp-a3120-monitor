Subsystem Lock

The Subsystem–Lock tab displays lock status and enables you to lock or unlock a subsystem controller. The lock prevents other sessions (including by the same user) from making a configuration change to the controller until the lock expires or a forced unlock is done. If another user attempts to change a controller setting, that user will see a message saying that the system is locked. When the user who locked the controller logs out, the lock is automatically released.

You can set the lock to last from one minute to one day. You can also release the lock before the scheduled time.

To VIEW the lock status for this subsystem:

  1. Click on the Subsystem in Tree View.
  2. Click on the Lock tab in Management View.
    The following information is displayed:
    • Lock Status – The User who set the lock in the current session can see the lock status.
    • Expiration Time – Amount of time left until the lock automatically releases.
    • Expire At Time – The date and time when the lock will automatically release.

To SET the lock for this subsystem:

  1. Click on the Subsystem in Tree View.
  2. Click on the Lock tab in Management View.
  3. Click on the Lock option button.
  4. Enter a time interval between 1 and 1440 minutes (one day) that you want the lock to stay active.
  5. Click the Submit button.

To RENEW an existing lock for this subsystem:

  1. Click on the Subsystem in Tree View.
  2. Click on the Lock tab in Management View.
  3. Click on the Renew option button.
  4. Enter a time interval between 1 and 1440 minutes (one day) that you want the lock to stay active.
    The renew time replaces the previous Expiration Time.
  5. Click the Submit button.

To RELEASE the lock for this subsystem:

  1. Click on the Subsystem in Tree View.
  2. Click on the Lock tab in Management View.
  3. If you are the User who set the lock, click on the Unlock option button.
    If another User set the lock and you are a Super User, click on the Unlock option button and check the Force Unlock box.
  4. Click the Submit button.
