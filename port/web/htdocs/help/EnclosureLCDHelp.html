Enclosure LCD Settings

The Enclosure–LCD Settings tab and LCD screen apply to subsystems only.
The LCD Settings tab enables you to make the Mode setting for the LCD screen.

To make the Mode setting for the LCD screen:

  1. Click the Subsytem icon in Tree View.
  2. Click the Enclosures icon.
  3. Click the Enclosure icon.
  4. Click the LCD Settings tab in Management View.
  5. From the Mode dropdown menu, choose the mode you want:
    • Read Only – Displays system information. Does not accept system settings
    • Read/Write – Displays system information and accepts system settings
    • Disable – Displays "disabled mode." No system information or settings
  6. Click the Submit button.
    Your setting change takes effect immediately.
